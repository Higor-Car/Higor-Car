## Projetos em destaque

### [Achou Promo](https://github.com/Higor-Car/promopost) · [achoupromos.com.br](https://achoupromos.com.br)

Plataforma de promoções para os comércios de Maurilândia, Turvelândia e Porteirão (GO). Os comércios parceiros pagam uma mensalidade e os consumidores acessam a vitrine de graça, sem login.

- Vitrine pensada para celular, com busca, filtro por cidade e categoria e página de cada comércio com botão de WhatsApp
- Promoções com período de validade, destaques e métricas de visualizações e cliques para os lojistas
- Geração da imagem "Promoções do dia" para o Instagram e QR codes para os comércios parceiros
- **Em produção** na AWS Lightsail com Nginx, Gunicorn, systemd e HTTPS (Let's Encrypt), com scripts de instalação, atualização e backup

`Python` `Django` `Nginx` `Gunicorn` `AWS Lightsail`

### [Loja Flask API](https://github.com/Higor-Car/loja-flask-api)

API REST para gerenciar produtos, clientes, pedidos e itens de pedido, com 20 endpoints.

- Autenticação com JWT e senhas protegidas com bcrypt
- Validação com marshmallow e documentação OpenAPI/Swagger gerada pelo flask-smorest
- Deploy na AWS EC2 com Gunicorn e systemd
- **CI/CD** com GitHub Actions: cada push na `main` atualiza o servidor automaticamente

`Python` `Flask` `JWT` `SQLite` `AWS EC2` `GitHub Actions`

### [Django Chatbot](https://github.com/Higor-Car/Django-Chatbot)

Chatbot com IA que roda localmente pelo Ollama, sem custo de API.

- Várias conversas com histórico salvo e contexto enviado ao modelo
- Respostas em Markdown renderizadas com segurança, sem bibliotecas externas
- Testes automatizados com o modelo simulado

`Python` `Django` `Ollama` `JavaScript`
